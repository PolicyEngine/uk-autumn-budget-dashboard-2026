# Living standards inputs

The Pre-measures forecast tab (`?tab=outlook`), and Population impact's growth and poverty cards with the measures, read `public/data/living_standards_outlook.json` (shape in [`docs/DATA_CONTRACT.md`](../../docs/DATA_CONTRACT.md)). `uk-budget-data living-standards` writes it from the files here and a baseline run on the pinned policyengine.py bundle and its certified Microcosm dataset (`src/uk_budget_data/living_standards/`). Until 24 October 2026 the file was copied from PolicyEngine/uk-living-standards-outlook; that repository is no longer its source.

The historical pre-Budget chart reads the March workbook through `living_standards/historical_forecast.py`, independently of the model installed for current projections. The workbook supplies eight OBR series. The archived model source supplies only explicit dated CPI after housing costs and social-rent inputs, and the 2030 mortgage-interest input that the March workbook lacks. Those values reproduce the historical inputs in the published 6.11.1/2.151.0 outlook. The model source describes its 2027 social-rent value as a placeholder and its 2030 mortgage-interest value as a carry from the November 2025 EFO; neither is an OBR March forecast. The reader evaluates no model formula and fills no missing year. It rejects missing or changed source bytes, unsupported years and missing literals. `check_pre_is_march` still rejects October values presented as March. The current projection engine and adopted economic overlay remain separate from these historical chart inputs.
