# Execution-plan wire evidence

The browser validates ordered execution plans and recomputes their identities from JSON. It treats carried module and function names as text. Runtime workers separately bind trusted functions, and publication retains its approval and data gates.

PolicyEngine's generators produce these schemas and vectors from the unreleased source checkpoint in [source-provenance.json](./source-provenance.json), which records each file hash. Regenerate from that upstream source and copy exact bytes, including the expected identities.

The browser rejects integral JavaScript Numbers outside the safe-integer range. Parsed JSON cannot distinguish an unsafe Python integer from a finite Python float with the same mathematical value. This consumer supports a narrower numeric domain than the Python API.
