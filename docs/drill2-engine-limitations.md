# Latest engine: included corrections and remaining gaps

The drill now runs UK **2.120.0/core 3.32.17**; its unchanged dataset was built with UK **2.100.0/core 3.32.5**. The user approved this drill-only mismatch on 5 October 2026. The earlier omissions list has been superseded: corrections through 2.120.0 are installed, not deliberately excluded. Calibration under this runtime remains unvalidated.

The table groups the official [2.120.0 changelog at release commit b5b0923](https://github.com/PolicyEngine/policyengine-uk/blob/b5b092312df7aa56a4e89c4b9b7c133507dea114/CHANGELOG.md). “Included” describes the code installed. Older stored dataset inputs can still bypass formula corrections, and missing newer inputs may use defaults. No runtime-versus-build effect on this dataset has been quantified.

Remaining limitations are the [dataset/runtime compatibility gaps](drill2-engine-gaps.md), national-only geography, fuel VAT comparison basis, possible renter-incidence differences and any explicitly declared calendar-to-fiscal proration for custom measures. Those are distinct from the fixes now installed. Do not label a risk as an observed engine defect without a reproducing example and source-rule check.
